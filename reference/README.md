# 外部来源目录

这里只存放只读的外部数据或代码，不混入项目依赖。当前位置、用途、许可和材料限制统一登记在[来源配置](../configs/datasets.json)，不在本文另存一份数量或可用状态。

| 分类 | 用途 |
| --- | --- |
| `sources/` | 构造任务的第一人称视频和标注 |
| `catalogs/` | 填充网站的真实条目与图片 |
| `candidates/` | 尚待核查用途或材料的候选来源 |
| `literature/` | 比较论文与只读参考，不作为任务流水线输入 |

检出版本和早期采集说明保留在本地维护文档中，不随本版代码发布。
