# Third-party references

This directory contains read-only external datasets or code checkouts used as research sources. They are not part of the first-party Benchmark Release and are ignored by version control. Do not edit these repositories or mix their dependencies with EgoCUA-Bench.

## Local checkouts

Source and revision information was verified on 2026-08-09. Except for the existing Ego2Web data mount, repositories were cloned with `--depth 1`. Only a small, provenance-recorded screening subset of HD-EPIC and EgoSchema media was downloaded; no bulk dataset release was mirrored.

## Scope boundary

The presence of a repository here does not imply that it evaluates end-to-end Agent execution. WAGIBench evaluates goal inference; SUPERGLASSES, EgoPoint, TeleEgo, and WearVQA-style datasets principally evaluate question answering, grounding, or memory; SAW-Bench evaluates situated spatial reasoning. Ego2Web is the direct web-execution baseline. Egocentric Co-Pilot is included only as a system-design reference.

Benchmarks with no confirmed public code repository are documented in [`docs/research/glass-benchmark-landscape.md`](../docs/research/glass-benchmark-landscape.md) rather than copied from unofficial mirrors.
